# AirPlay 2 Add-ons für Home Assistant

## Installation
1. In Home Assistant: **Einstellungen → Add-ons → Add-on-Store → ⋮ → Repositories**
2. URL dieses GitHub-Repos eintragen und hinzufügen
3. **AirPlay 2 Receiver** installieren (der Build dauert auf einem Pi 4 einige Minuten)
4. Optionen prüfen, starten – das Gerät erscheint in AirPlay auf iPhone/Mac

Dokumentation: siehe [airplay2/DOCS.md](airplay2/DOCS.md)
